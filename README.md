# 工程測量乙級術科練習

工程測量乙級技術士技能檢定術科 10 題的線上練習網站，依「(1090329 起報檢者適用) 乙級工程測量技術士術科測試應檢參考資料」製作，記錄表與答案紙照原格式呈現。

**線上使用：** https://maxcoffeeyu.github.io/survey-level-b-practice/

## 練習模式

1. **術科外業＋內業練習**：第一人稱操作儀器。
   - 水準類（第 6～10 題）：自動水準儀，5mm 式水準尺自行判讀上、中、下絲。
   - 經緯儀類（第 1～4 題）：電子經緯儀（HR／V 顯示、0SET、正倒鏡），2mm 鋼捲尺量距。
   - 第 5 題：室內計算後實地放樣（HSET、HOLD、指揮小幫手持測針、捲尺定距）。
   - 結束外業後發給已知資料，完成內業計算交卷，與場地真值比對評分。
2. **純內業練習**：系統隨機生成外業數據，只做內業計算，依官方時間計時。
3. **教學引導模式**：使用官方範例數據，依計算順序一格一格說明公式與代入數值。

交卷後依官方評審表評分，並可點選欄位查看計算方式。

## 使用方式

直接開啟網站即可，不需安裝。作答進度存在瀏覽器中，換題或重新整理不會遺失。建議使用電腦或平板操作第一人稱外業模式。

本網站為教學練習用途，評分結果僅供參考，實際檢定以監評人員評分為準。
